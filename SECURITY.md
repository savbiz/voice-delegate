# Security policy

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/savbiz/voice-delegate/security/advisories/new)
to contact the maintainers. Do not disclose vulnerabilities in public issues or pull
requests. Include the affected commit/version, impact, and minimal reproduction steps;
remove API keys, invitation tokens, session keys, transcripts and personal data.

We will acknowledge private vulnerability reports within 72 hours of receipt. We will
coordinate investigation, remediation and disclosure through the private report. The
acknowledgement window is not a promise that a fix will be available within 72 hours.

## Supported versions

Security fixes target the current `main` branch. Update to the latest reviewed commit;
older candidate snapshots are not maintained separately.
