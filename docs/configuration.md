# Configuration

Generated from `backend/src/voice_delegate/config.py`. Do not edit this file directly.
Run `uv run python scripts/build_configuration.py`; pytest checks for drift.

Settings load at process startup. Process environment overrides root `.env`; restart
after changes. JSON arrays/objects are required for origins, hosts and invitations.
Declared defaults below never read your environment or reveal configured secrets.
Boolean flags accept `true` or `false`. `enum` lists every application-allowed choice;
numeric bounds and collection/string limits are listed in field validation.
A plain string is not an enumerated model/voice catalogue: provider/account support
still determines whether that value works. Empty optional credentials disable no
feature automatically; enabling a dependent feature can require its credentials.
See [local profiles](local-development.md#copyable-local-configuration) and the
commented [server template](../.env.example) for meanings and examples.

## Cross-field validator rules

Every configuration is also checked by the exact validator below. This includes
production HTTPS and host restrictions, invitation length/uniqueness, durable
public-demo quotas, Azure origins, remote-worker credentials and provider choices.
The code is generated verbatim so changes to any validator fail the drift test.
Field types use Pydantic's normal environment parsing; this is not strict JSON typing.

```python
@model_validator(mode="after")
def validate_elevenlabs(self) -> "Settings":
    if self.voice_provider == "elevenlabs" and not self.elevenlabs_enabled:
        message = "ElevenLabs adapter requires VOICE_ELEVENLABS_ENABLED"
        raise ValueError(message)
    if self.elevenlabs_enabled and (
        not self.elevenlabs_api_key.get_secret_value() or not self.elevenlabs_agent_id
    ):
        message = "ElevenLabs requires ELEVENLABS_API_KEY and VOICE_ELEVENLABS_AGENT_ID"
        raise ValueError(message)
    if self.voice_provider == "elevenlabs" and not self.intent_cancellation:
        message = "ElevenLabs async delegation requires VOICE_INTENT_CANCELLATION"
        raise ValueError(message)
    if self.voice_provider == "elevenlabs" and (self.fallback_enabled or self.native_clients):
        message = "ElevenLabs does not support cross-vendor fallback or native clients"
        raise ValueError(message)
    if (
        self.voice_provider == "elevenlabs"
        and self.delegation_timeout_seconds + self.delivery_timeout_seconds > 110
    ):
        message = "ElevenLabs delegation plus delivery wait must fit the SDK callback deadline"
        raise ValueError(message)
    return self

def validate_web_search(self) -> "Settings":
    self.web_search_domains = list(
        dict.fromkeys(domain_name(value) for value in self.web_search_domains)
    )
    if (
        self.web_search
        and self.worker_execution == "local"
        and not self.tavily_api_key.get_secret_value()
    ):
        message = "Web search requires TAVILY_API_KEY on the worker host"
        raise ValueError(message)

@model_validator(mode="after")
def validate_origins(self) -> "Settings":
    """Accept the deprecated singular setting only when no list was supplied."""
    if self.allowed_origin is not None and "allowed_origins" not in self.model_fields_set:
        self.allowed_origins = [self.allowed_origin]
    for origin in self.allowed_origins:
        if self.native_clients and origin == "capacitor://localhost":
            continue
        parsed = urlsplit(origin)
        if (
            parsed.scheme not in {"http", "https"}
            or not parsed.hostname
            or parsed.username
            or parsed.password
            or parsed.path
            or parsed.query
            or parsed.fragment
            or "*" in parsed.netloc
            or origin != f"{parsed.scheme}://{parsed.netloc}"
            or origin != str(HttpUrl(origin)).removesuffix("/")
        ):
            message = (
                "Allowed origins must be canonical HTTP(S) origins: "
                "lowercase hosts, no paths or default ports"
            )
            raise ValueError(message)
    return self


@model_validator(mode="after")
def validate_production(self) -> "Settings":
    """Require an explicit browser origin and access gate on public deployments."""
    if self.decisions_cancel and (
        not self.intent_cancellation or not self.openai_api_key.get_secret_value()
    ):
        message = "Decisions cancellation requires intent cancellation and OPENAI_API_KEY"
        raise ValueError(message)
    if self.instance_id and not self.public_demo:
        message = "Multiple API instances require public-demo identity and quota controls"
        raise ValueError(message)
    if self.worker_execution == "remote":
        from urllib.parse import urlparse

        target = urlparse(self.worker_service_url)
        if (
            target.scheme not in {"http", "https"}
            or not target.hostname
            or target.username
            or target.password
            or target.query
            or target.fragment
        ):
            message = "Worker URL must be an HTTP(S) service origin"
            raise ValueError(message)
        if len(self.worker_service_token.get_secret_value()) < 32:
            message = "Remote worker requires a service token of at least 32 characters"
            raise ValueError(message)
    if len(self.invite_tokens) > 100:
        message = "At most 100 named invitations are supported"
        raise ValueError(message)
    values = [token.get_secret_value() for token in self.invite_tokens.values()]
    if any(not name or len(name) > 64 for name in self.invite_tokens):
        message = "Invitation names must contain 1 to 64 characters"
        raise ValueError(message)
    if any(len(value) < 32 for value in values) or len(set(values)) != len(values):
        message = "Invitations require unique random tokens of at least 32 characters"
        raise ValueError(message)
    if self.public_demo and (not values or self.quota_database == ":memory:"):
        message = "Public demo requires named invitations and durable quota storage"
        raise ValueError(message)
    if self.public_demo and self.environment != "production":
        message = "Public demo requires production configuration"
        raise ValueError(message)
    if self.fallback_enabled or self.voice_provider == "azure":
        from urllib.parse import urlparse

        endpoint = urlparse(self.azure_endpoint)
        if (
            endpoint.scheme != "https"
            or not endpoint.hostname
            or not endpoint.hostname.endswith(".openai.azure.com")
            or endpoint.path not in {"", "/"}
            or endpoint.query
            or endpoint.fragment
            or endpoint.username
            or endpoint.password
            or endpoint.port not in {None, 443}
        ):
            message = "Azure endpoint must be an HTTPS Azure OpenAI resource origin"
            raise ValueError(message)
        if not self.azure_api_key.get_secret_value():
            message = "Azure fallback requires VOICE_AZURE_API_KEY"
            raise ValueError(message)
    if self.fallback_enabled and self.voice_provider == "azure":
        message = "Azure cannot be both primary and fallback"
        raise ValueError(message)
    if self.worker_mode != "offline" and not self.openai_api_key.get_secret_value():
        message = "Paid worker modes require OPENAI_API_KEY"
        raise ValueError(message)
    if self.environment == "production":
        if "testserver" in self.allowed_hosts:
            message = "Production requires explicit VOICE_ALLOWED_HOSTS without testserver"
            raise ValueError(message)
        if not self.invite_tokens and len(self.access_token.get_secret_value()) < 24:
            message = "Production requires VOICE_ACCESS_TOKEN of at least 24 characters"
            raise ValueError(message)
        if any(
            not origin.startswith("https://")
            and not (self.native_clients and origin == "capacitor://localhost")
            for origin in self.allowed_origins
        ):
            message = "Production requires an HTTPS frontend origin"
            raise ValueError(message)
    return self
```

## Browser origin compatibility

Use `VOICE_ALLOWED_ORIGINS` as a JSON array of exact origins. The deprecated
`VOICE_ALLOWED_ORIGIN` accepts one origin only when no list was supplied.
The list takes precedence if both variables are configured. Production requires
HTTPS for every allowed browser origin. With `VOICE_NATIVE_CLIENTS=true`, the exact
`capacitor://localhost` iOS origin may also be explicitly listed. Android uses
`https://localhost`. Neither native origin is added automatically. Routes, CORS
and limiter responses share the list.
Origins must use browser serialization: lowercase/punycode hostnames and no
explicit default ports (`:443` for HTTPS or `:80` for HTTP). Noncanonical values
are rejected at startup; non-default ports and canonical IPv6 origins are allowed.

## Frontend and auxiliary variables

These are not backend Settings and do not belong in the server template:

| Variable | Accepted value and purpose |
|---|---|
| `VITE_API_BASE_URL` | Empty for the local Vite proxy, or a backend HTTP(S) origin; public build-time URL. |
| `VOICE_NATIVE_BUILD` | Exact `true` opts into the native build script; required by `pnpm native:sync`. |
| `VITE_NATIVE_LIVE` | Exact `true` enables the experimental native voice path; otherwise off. |
| `VITE_OFFLINE_STACK` | Exact `true` selects the container offline-stack UI; otherwise off. |
| `BRAINTRUST_API_KEY` | Optional private eval-upload credential, never a frontend value. |

Frontend build flags live in the frontend build environment, not root `.env`.
CLI-only eval, benchmark and hosting options are documented in their own guides.

## Hosting configuration

Vercel serves the static frontend: set only `VITE_API_BASE_URL` to the backend HTTPS
origin. It is public build-time configuration and requires a new frontend build.
Set `OPENAI_API_KEY` and applicable `VOICE_*` settings on Railway or Render, never
in browser-prefixed variables. Keep provider keys, invitation and worker tokens private.
Railway-specific variables such as `RAILWAY_DOCKERFILE_PATH` and `RAILWAY_RUN_UID`
belong to the hosting platform, not Settings. See [deployment](../deployment/README.md).

Quota meanings and incident procedures: [operations](operations.md).
