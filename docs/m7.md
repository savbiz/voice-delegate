# M7 — advanced voice experience candidate

Choose a response language before starting: follow the current speaker, Italian, English,
Spanish, French or German. Conversation mode answers questions and delegates work. Mirror
mode asks the voice model to translate/restate speech in the chosen language without
answering or executing it; the manager additionally blocks worker delegation in that mode.
Preferences are finite enums, immutable during the call, and retained during fallback.
These are model instructions, not a guarantee of translation quality.

The browser shows a bounded extractive recap: latest user request, latest assistant excerpt,
and an interruption marker. It clears obsolete answers on interruption and updates the
request when the user corrects themselves. It does not invent a completed action or produce
a semantic summary. Source transcripts and recap remain ephemeral session data. Old tasks
cannot overwrite the new generation's worker result. Voice fragments remain approximate.

Accessibility additions: labeled keyboard-operable language/style controls, mute/unmute
without stopping capture, larger captions, focus outlines, reduced-motion styling, and
polite status/recap announcements. The original visible captions and audio controls remain.
These checks are not a claim of full WCAG conformance or a screen-reader audit.

`VOICE_VOICE_PROVIDER=live|realtime|azure` selects the primary transport. The new `realtime`
choice uses `VOICE_REALTIME_MODEL` (default `gpt-realtime`) and `OPENAI_API_KEY`, a fixed OpenAI
endpoint, bearer authentication, server-side tools and call hangup. Azure can still be the
single fallback for Live or Realtime. Azure primary cannot fall back to itself.

Offline tests cover five languages, mirror delegation suppression, a mixed Italian/English
correction, bounded recap and OpenAI Realtime authentication/cleanup. Live multilingual
pronunciation, translation fidelity, acoustic interruption and provider access still need
actual calls and listening; no measured scores are invented.
